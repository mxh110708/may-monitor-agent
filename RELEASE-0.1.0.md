# May Monitor Agent 0.1.0

Promote the accepted 0.1.0-rc.4 monitoring implementation without functional
changes. Retain bounded collectors and probes, reconnect behavior, dedicated
agent authentication, installation identity checks and credential-error
redaction. Remote control and automatic updates remain disabled.

Linux amd64 is the production acceptance target. Linux arm64 and Windows amd64
are cross-compiled only. Publishing does not install any desktop update.
